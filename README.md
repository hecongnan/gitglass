# Gitglass TUI

在 Linux 终端中审阅本地 Git 更改。三栏布局：左侧文件树、中间代码 Diff、右侧提交历史。使用 Python 标准库 `curses`，无需浏览器、服务端口或 pip 依赖。

## 直接运行

安装命令后即可从任意目录启动（安装方法见下文）：

```bash
gitglass                       # 扫描当前目录中的仓库
gitglass ~/Projects            # 扫描指定目录
gitglass ~/Projects ~/Work     # 扫描多个目录
gitglass --theme dark          # 深色终端界面
```

也可以使用 `--root` 重复添加扫描目录，使用 `--interval 10` 修改刷新间隔（默认 30 秒，最短 5 秒）。

运行要求：Linux、Python 3.10+（含 curses）、Git、支持 UTF-8 的交互终端，至少 96 列 × 24 行。推荐 140 列以上，便于显示并排 Diff。默认浅色配色，支持 256 色；基础终端会使用兼容配色。

## 配色

浅色与深色主题均提供丰富的语义配色：蓝色文件栏、青色 Diff 栏、粉紫色历史栏；不同文件类型使用不同颜色，修改为琥珀色、新增为绿色、未跟踪为青色、删除为红色。提交按 feat / fix / refactor 等类型着色，哈希与作者分别着色。代码包含轻量的关键字、字符串、数字、注释和装饰器高亮，并保留 Diff 的红绿行背景。基础色终端自动降级，未启用颜色的终端使用反显表示焦点。

## 按键

| 按键 | 操作 |
| --- | --- |
| `Tab` / `Shift+Tab` | 在三栏之间切换焦点 |
| `1` / `2` / `3` | 文件树 / Diff / 提交历史 |
| `j` / `k`、上下箭头 | 移动选择或滚动 Diff |
| `Enter` / 空格 | 打开文件、折叠文件夹、查看选中的提交 |
| `PgUp` / `PgDn` | 翻页浏览 Diff |
| `h` / `l`、左右箭头 | 水平滚动代码 |
| `g` / `G` | 当前栏顶部 / 底部 |
| `/` | 按路径筛选文件，Enter 应用，Esc 取消；空筛选恢复所有文件 |
| `r` | 选择发现的仓库（包括直接打开的干净仓库） |
| `a` | 输入新的扫描目录，支持 `~` |
| `s` | 统一 / 并排 Diff |
| `v` | 切换当前文件的已查看状态 |
| `u` | 返回未提交更改 |
| `R` | 手动刷新仓库与文件 |
| `?` | 打开帮助 |
| `Esc` | 关闭弹窗或取消输入 |
| `q` | 退出 |

支持鼠标点击文件、提交以及滚轮滚动（取决于终端）。输入目录或筛选文本时，`Ctrl+U` 清空输入。

## 功能和边界

- 从仓库根目录或任意子目录启动时，优先加载该仓库，无论是否有未提交更改；扫描普通项目目录时，继续自动发现其中有更改的仓库。每 30 秒刷新。
- 工作区干净时，左侧显示所有 Git 跟踪文件，中间显示所选文件的只读预览，右侧正常显示提交历史；有更改时切换回更改文件和 Diff。
- 支持 `.git` 目录及 worktree 的 `.git` 文件。
- 文件树可折叠；支持 Unicode 文件名、独立新旧行号、增删颜色和水平滚动。
- 查看当前工作树相对 HEAD 的综合更改，以及最近 60 次提交的文件差异。
- 读取 Git 的操作在后台线程执行，扫描期间仍可滚动、打开帮助或退出。
- 所有操作只读，不提交、不暂存、不回退、不上传代码，并禁用 Git 的可选索引写入。
- 没有发现仓库时显示空状态；按 `a` 添加目录。TUI 不使用演示数据。
- 默认扫描深度 6 层，每个扫描根目录最多访问 15,000 个子目录，跳过隐藏目录、node_modules、vendor、target 等构建目录。更深的仓库可以添加更具体的扫描目录。
- 未跟踪文件预览上限 1 MB，单文件 Diff 上限 200 万字符；二进制文件仅显示提示。合并提交暂不提供多父提交比较。
- 已查看标记在当前进程中保存；切换仓库或提交会清空。刷新和重新读取相同提交会保留标记。扫描目录设置仅保留在本次运行期间，可通过启动参数固定配置。

## 在其他位置安装命令

保留此目录，然后在目录内运行：

```bash
./gitglass --help
mkdir -p ~/.local/bin
ln -s "$(pwd)/gitglass" ~/.local/bin/gitglass
```

确保 `~/.local/bin` 已在 `PATH` 中。直接运行绝对路径也可以，不需要安装步骤。

## 文件

- `gitglass`：可执行入口，支持通过符号链接安装到 PATH。
- `tui.py`：终端界面及键盘操作。
- `server.py`：共用的本地 Git 读取与扫描逻辑。
- `static/`：保留的早期浏览器版界面；不会在启动 TUI 时运行。若需要，仍可执行 `python3 server.py --root ~/Projects` 单独启动浏览器版。

验证已覆盖：真实伪终端启动、三栏布局、文件打开、并排切换、提交导航、文件筛选、帮助、仓库选择器、终端缩放、退出，以及 Git 扫描、暂存更改、未跟踪文本、二进制、重命名与首次提交读取。
